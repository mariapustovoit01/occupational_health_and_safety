# occupational_health_and_safety 
Мокра підлога (як джерело небезпеки) виникає в цехах, офісах, коридорах і виробничих приміщеннях після прибирання або через розлиту рідину. Така ситуація створює загрозу для працівників. Є можливість послизнутися, впасти та отримати забій. Щоб запобігти травмам, необхідно встановлювати попереджувальні знаки біля мокрих ділянок підлоги. Також потрібно своєчасно прибирати розлиту рідину та перевіряти, чи підлога стала сухою, перш ніж дозволяти вільний прохід.
